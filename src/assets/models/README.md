# Place your 3D Human Avatar Model Here

You can place your 3D humanoid avatar file here:
`src/assets/models/interviewer.glb`

Supported formats:
- `.glb` (recommended binary glTF)
- Ready Player Me full-body avatars
- Mixamo rigged characters
- MakeHuman / Blender glTF exports

When `interviewer.glb` is placed in this folder, Career Sprint will automatically detect and load it!
If no file is present, the application runs the high-fidelity procedural realistic human avatar fallback.
